## Project Coding Rules (English)

1. **Component Isolation Rule**  
   - When working on a specific component (e.g., the Shipping Calculator), **do NOT modify any other files** without explicit, written permission from the project owner.  
   - If a change in another file is technically required, first *ask for approval*, clearly explaining *what* you intend to modify and *why*. Only proceed after approval is granted.

2. **Documentation & Descriptions**  
   - Do **NOT** create or update READMEs or other documentation files unless explicitly requested.  
   - Change descriptions must be *concise*: list **what** changed and **where**. Avoid unnecessary details.

3. **Enforcement**  
   - These rules are **mandatory**. Violations will result in the change being rejected and will require a full rollback.
