# Глобальный кэш маршрутов

## Проблема

### До изменений:

При переключении между страницами `/tarify` ↔ `/tarify-iz-moskvy` и `/pereezd` ↔ `/pereezd-iz` пользователь сталкивался с задержкой загрузки данных маршрутов (1 секунда) **на каждой странице**.

**Причина:**  
React Router при переходе между страницами размонтирует и заново монтирует компоненты. Это приводило к сбросу локального `state` в компоненте `RoutesAccordion`, и данные загружались заново с задержкой.

```
Пользователь на /tarify
  └─ Данные загружены (1 сек задержка)
  └─ Переключается на /tarify-iz-moskvy
      └─ Компонент размонтируется
      └─ Компонент монтируется заново
      └─ State сброшен → routeCache = null
      └─ ❌ Данные загружаются снова (еще 1 сек задержка!)
```

## Решение

Создан **глобальный менеджер кэша** `routeCacheManager.ts`, который сохраняет данные маршрутов на уровне модуля (вне React компонентов).

### Преимущества:

✅ **Загрузка только один раз** - данные загружаются при первом посещении любой страницы  
✅ **Мгновенное переключение** - при переходе между страницами данные доступны сразу  
✅ **Экономия ресурсов** - нет повторных запросов на загрузку JSON  
✅ **Улучшенный UX** - нет задержек при навигации  

## Техническая реализация

### 1. Новый файл: `src/utils/routeCacheManager.ts`

```typescript
// Глобальный кэш (существует всё время работы приложения)
let globalRouteCache: RouteData | null = null;

// Получить кэшированные данные
export const getRouteCache = (): RouteData | null => {
  return globalRouteCache;
};

// Загрузить данные с задержкой (только если еще не загружены)
export const loadRouteCacheDelayed = async (delay: number = 1000): Promise<RouteData> => {
  if (globalRouteCache) {
    return Promise.resolve(globalRouteCache); // Сразу возвращаем
  }
  
  // Загружаем с задержкой только в первый раз
  return new Promise((resolve) => {
    setTimeout(async () => {
      const data = await import("@/data/routeCache.json");
      globalRouteCache = data.default;
      resolve(globalRouteCache);
    }, delay);
  });
};
```

### 2. Обновлённый `RoutesAccordion.tsx`

```typescript
import { getRouteCache, loadRouteCacheDelayed } from "@/utils/routeCacheManager";

// Инициализация с данными из глобального кэша (если есть)
const [routeCache, setRouteCache] = useState<any>(getRouteCache());

useEffect(() => {
  // Проверяем глобальный кэш
  const cachedData = getRouteCache();
  if (cachedData) {
    setRouteCache(cachedData); // Используем сразу!
    return;
  }

  // Загружаем только если данных еще нет
  loadRouteCacheDelayed(1000).then((data) => {
    setRouteCache(data);
  });
}, []); // Выполняется только при монтировании
```

## Как это работает

### Первое посещение (например, `/tarify`):

```
1. Пользователь открывает /tarify
2. RoutesAccordion монтируется
3. getRouteCache() → null (данных еще нет)
4. Запускается loadRouteCacheDelayed(1000)
   └─ Задержка 1 секунда
   └─ Загрузка routeCache.json
   └─ Сохранение в globalRouteCache
5. ✅ Данные отображаются
```

### Переключение на другую страницу (например, `/tarify-iz-moskvy`):

```
1. Пользователь кликает "Из Москвы"
2. Навигация на /tarify-iz-moskvy
3. RoutesAccordion размонтируется и монтируется заново
4. getRouteCache() → данные есть! ✅
5. setRouteCache(cachedData)
6. ✅ Данные отображаются МГНОВЕННО (без задержки!)
```

### Последующие переключения:

```
/tarify → /tarify-iz-moskvy → /tarify → /pereezd → /pereezd-iz
   ↓           ↓                ↓          ↓           ↓
 1 сек      мгновенно      мгновенно  мгновенно   мгновенно
```

## Дополнительные возможности

### Очистка кэша (для разработки/тестирования):

```typescript
import { clearRouteCache } from "@/utils/routeCacheManager";

// Очистить кэш и заставить загрузить данные заново
clearRouteCache();
```

### Защита от гонки условий:

Менеджер кэша защищен от множественных одновременных запросов:

```typescript
// Если два компонента одновременно запросят данные:
Promise.all([
  loadRouteCacheDelayed(1000), // Компонент 1
  loadRouteCacheDelayed(1000)  // Компонент 2
]);

// Загрузка произойдет только ОДИН раз
// Оба компонента получат одни и те же данные
```
