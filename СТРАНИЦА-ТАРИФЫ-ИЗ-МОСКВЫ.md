# Страница "Тарифы из Москвы"

## Описание

Страница `/tarify-iz-moskvy` была создана для рекламных кампаний Яндекс Директ, ориентированных на клиентов, которые ищут доставку **из Москвы** в другие города.

## URL страницы

**Продакшн:** `https://nordatrans.ru/tarify-iz-moskvy/`

**Локально:** `http://localhost:8081/tarify-iz-moskvy`

## Отличия от страницы `/tarify`

Страница `/tarify-iz-moskvy` полностью идентична странице `/tarify` с **единственным отличием**:

### В аккордеоне маршрутов по умолчанию активна кнопка "Из Москвы"

**На странице `/tarify`:**
```tsx
<RoutesAccordion />
// По умолчанию активна кнопка "В Москву"
```

**На странице `/tarify-iz-moskvy`:**
```tsx
<RoutesAccordion initialDirection="from-moscow" />
// По умолчанию активна кнопка "Из Москвы"
```

## Структура файла

**Файл:** `src/pages/TariffyIzMoskvy.tsx`

Это полная копия файла `src/pages/Tariffs.tsx` с изменением на строке 620:
```tsx

```

## Компоненты на странице

Страница включает все те же компоненты, что и `/tarify`:

1. **Header** - навигационное меню
2. **Hero секция** - заголовок с описанием
3. **Калькулятор доставки** (`ShippingCalculatorForm`)
4. **Аккордеон маршрутов** (`RoutesAccordion`) - с активной кнопкой "Из Москвы"
5. **Секция "Работаем быстро"** (`WorkProcess`)
6. **Отзывы** (`Reviews`)
7. **Яндекс.Метрика** (`YandexMetrika`)
8. **Footer** - футер сайта

## Зачем нужна отдельная страница?

### 1. SEO и контекстная реклама
- Отдельный URL для рекламных кампаний Яндекс Директ
- Таргетинг на пользователей, которые ищут доставку **из Москвы**
- Улучшенная релевантность страницы для поисковых запросов

### 2. Улучшенный UX
- Пользователь сразу видит нужное направление маршрутов
- Не нужно переключать кнопку "В Москву" → "Из Москвы"
- Быстрый доступ к информации

### 3. Аналитика
- Отдельная страница позволяет отслеживать конверсии для направления "Из Москвы"
- Можно анализировать поведение пользователей отдельно

## Обновление контента

⚠️ **Важно:** При обновлении контента на странице `/tarify` необходимо синхронизировать изменения со страницей `/tarify-iz-moskvy`.

### Варианты синхронизации:

**Вариант 1: Ручное обновление**
- Внести изменения в `Tariffs.tsx`
- Повторить те же изменения в `TariffyIzMoskvy.tsx`

**Вариант 2: Автоматическая синхронизация (будущее улучшение)**
- Создать общий компонент с контентом
- Передавать `initialDirection` как пропс
- Использовать один компонент для обеих страниц

## Техническая информация

### Файловая структура
```
src/
  pages/
    Tariffs.tsx              # Базовая страница тарифов (В Москву)
    TariffyIzMoskvy.tsx      # Страница тарифов (Из Москвы)
  components/
    RoutesAccordion.tsx      # Компонент аккордеона с параметром initialDirection
```

### Роутинг
```tsx
// src/App.tsx
<Route path="/tarify" element={<Tariffs />} />
<Route path="/tarify-iz-moskvy" element={<TariffyIzMoskvy />} />
```

## Тестирование

### Локальное тестирование
```bash
npm run dev
```

Откройте в браузере:
1. `http://localhost:8081/tarify` - проверьте, что активна кнопка "В Москву"
2. `http://localhost:8081/tarify-iz-moskvy` - проверьте, что активна кнопка "Из Москвы"

### Проверка на продакшн
1. Откройте `https://nordatrans.ru/tarify-iz-moskvy/`
2. Убедитесь, что в аккордеоне маршрутов активна кнопка "Из Москвы"
3. Проверьте работу калькулятора
4. Убедитесь, что формы отправляются корректно

## Метрики для отслеживания
