# Страница "Переезд из Москвы"

## Описание

Страница `/pereezd-iz` была создана для рекламных кампаний Яндекс Директ, ориентированных на клиентов, которые ищут услуги переезда **из Москвы** в другие города.

## URL страницы

**Продакшн:** `https://nordatrans.ru/pereezd-iz/`

**Локально:** `http://localhost:8081/pereezd-iz`

## Отличия от страницы `/pereezd`

Страница `/pereezd-iz` полностью идентична странице `/pereezd` с **единственным отличием**:

### В аккордеоне маршрутов по умолчанию активна кнопка "Из Москвы"

**На странице `/pereezd`:**
```tsx
<RoutesAccordion />
// По умолчанию активна кнопка "В Москву"
```

**На странице `/pereezd-iz`:**
```tsx
<RoutesAccordion initialDirection="from-moscow" />
// По умолчанию активна кнопка "Из Москвы"
```

## Структура файла

**Файл:** `src/pages/PereezdIz.tsx`

Это полная копия файла `src/pages/Moving.tsx` с изменением на строке 2635:
```tsx
<RoutesAccordion initialDirection="from-moscow" />
```

## Компоненты на странице

Страница включает все те же компоненты, что и `/pereezd`:

1. **Header** - навигационное меню
2. **Hero секция** - заголовок "Междугородние переезды без проблем!"
3. **Преимущества** - карточки с преимуществами услуг
4. **Калькулятор переезда** - специализированная форма для расчета стоимости переезда
5. **Аккордеон маршрутов** (`RoutesAccordion`) - с активной кнопкой "Из Москвы"
6. **Секция "Работаем быстро"** (`WorkProcess`)
7. **Отзывы** (`Reviews`)
8. **Секция "Любая форма оплаты"**
9. **Яндекс.Метрика** (`YandexMetrika`)
10. **Footer** - футер сайта

## Зачем нужна отдельная страница?

### 1. SEO и контекстная реклама
- Отдельный URL для рекламных кампаний Яндекс Директ
- Таргетинг на пользователей, которые ищут переезд **из Москвы**
- Улучшенная релевантность страницы для поисковых запросов

### 2. Улучшенный UX
- Пользователь сразу видит маршруты из Москвы
- Не нужно переключать кнопку "В Москву" → "Из Москвы"
- Быстрый доступ к информации о переездах из столицы

### 3. Аналитика
- Отдельная страница позволяет отслеживать конверсии для направления "Из Москвы"
- Можно анализировать спрос на переезды из Москвы отдельно от переездов в Москву
- Оптимизация рекламных кампаний на основе данных

## Обновление контента

⚠️ **Важно:** При обновлении контента на странице `/pereezd` необходимо синхронизировать изменения со страницей `/pereezd-iz`.

### Варианты синхронизации:

**Вариант 1: Ручное обновление (текущий)**
- Внести изменения в `Moving.tsx`
- Повторить те же изменения в `PereezdIz.tsx`

**Вариант 2: Автоматическая синхронизация (будущее улучшение)**
- Создать общий компонент с контентом
- Передавать `initialDirection` как пропс
- Использовать один компонент для обеих страниц
