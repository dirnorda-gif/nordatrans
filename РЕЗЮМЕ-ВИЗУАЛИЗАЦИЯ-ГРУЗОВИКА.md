# 🚚 Резюме: Визуализация загрузки грузового автомобиля

## ✨ Что было сделано

Создана **интерактивная двойная визуализация** загрузки грузового автомобиля для калькулятора в разделе "Домашний переезд". Визуализация показывает **реальное фото грузовика** из автопарка компании слева и **вид кузова сверху** справа с анимированным заполнением и сеткой палет.

## 🎯 Основные возможности

### 1. **Двойная визуализация с реальными фото**
- **Слева**: Реальные фотографии грузовиков из автопарка компании
- **Справа**: Вид кузова сверху с анимированным заполнением
- Сетка паллето-мест, показывающая загруженность
- Плавные transitions для комфортного восприятия

### 2. **Умная цветовая индикация**
Цвет заполнения меняется в зависимости от загруженности:
- 🟢 **Зеленый** (0-30%) — Легкая загрузка
- 🔵 **Синий** (30-60%) — Оптимальная загрузка
- 🟠 **Оранжевый** (60-90%) — Хорошая загрузка
- 🔴 **Красный** (90-100%) — Максимальная загрузка

### 3. **Реальные данные из автопарка**
- Фотографии: `/1.webp`, `/2.webp`, `/3.webp`, `/4.webp`, `/5.webp`, `/7.webp`
- Точные размеры кузова (длина × ширина × высота)
- Грузоподъемность для каждого типа транспорта
- Количество паллето-мест

### 4. **Визуализация паллето-мест**
- Динамическая сетка палет в кузове (вид сверху)
- Количество палет зависит от типа грузовика
- Показывает примерное количество загруженных палет
- Помогает понять реальную вместимость

### 5. **Полная информация о транспорте**
- Название грузовика в заголовке
- Размеры кузова под визуализацией
- Описание типа транспорта
- Текущий объем и максимальная вместимость
- Процент заполнения с цветовой индикацией

### 6. **Интеллектуальные подсказки**
Система автоматически дает краткие рекомендации:
- При малой загрузке: "💡 Можно добавить груз"
- При оптимальной: "✓ Оптимально"
- При максимальной: "⚠️ Проверьте габариты"

## 🚀 Как использовать

### Для пользователей сайта:
1. Выберите тип перевозки "Домашний переезд"
2. Заполните города отправления и назначения
3. Нажмите "Далее"
4. Используйте слайдер объема
5. Визуализация появится автоматически

### Для разработчиков:
```tsx
import { TruckVisualization } from "@/components/TruckVisualization";

<TruckVisualization
  currentVolume={volumeSteps[volumeIndex]}
  maxVolume={82}
  truckName="Газель"
  truckCapacity="до 1,5 т"
  truckDescription="Для небольших переездов"
/>
```
