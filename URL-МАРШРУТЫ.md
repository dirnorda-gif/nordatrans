## Как изменить URL страницы

Если в будущем потребуется изменить URL какой-либо страницы, необходимо обновить следующие файлы:

### 1. `src/App.tsx`
Измените путь в роуте:
```tsx
<Route path="/новый-url" element={<Компонент />} />
```

### 2. `src/components/Header.tsx`
Обновите в двух местах:

**а) Определение активной секции (useEffect):**
```tsx
} else if (location.pathname === '/новый-url') {
  setActiveSection("название-секции");
```

**б) Функция навигации:**
```tsx
const handleНазваниеClick = () => {
  setActiveSection("название-секции");
  navigate('/новый-url');
};
```

### 3. `src/components/Footer.tsx`
Если есть ссылка в футере:
```tsx
<button
  onClick={() => navigate('/новый-url')}
  className="..."
>
  Название
</button>
```

### 4. Другие страницы и компоненты
Проверьте все файлы на наличие старого URL:
```bash
grep -r "/старый-url" src/
```

## Важные замечания

⚠️ **Перед изменением URL:**
1. Убедитесь, что новый URL не конфликтует с существующими
2. Проверьте настройки рекламных кампаний (Яндекс Директ, Google Ads)
3. Обновите robots.txt и sitemap.xml при необходимости
4. Настройте редиректы со старых URL на новые (если требуется)

⚠️ **После изменения URL:**
1. Протестируйте все ссылки на сайте
2. Проверьте навигацию через меню
3. Убедитесь, что формы редиректят корректно
4. Обновите URL в рекламных кампаниях

## Настройка редиректов

Если нужно настроить редиректы со старых URL на новые (чтобы старые ссылки продолжали работать), это делается на уровне сервера или в `vite.config.ts` для разработки.

Пример настройки редиректа в Vite:
```ts
// vite.config.ts
export default defineConfig({
  // ... другие настройки
  server: {
    proxy: {
      '/tariffs': {
        target: 'http://localhost:5173',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/tariffs/, '/tarify')
      }
    }
  }
});
```

Для продакшн-сервера настройте редиректы в конфигурации веб-сервера (Nginx, Apache и т.д.).

## Проверка изменений

1. **Локальная проверка:**

2. **Поиск старых URL:**
```bash
grep -r "/старый-url" src/
```

3. **Проверка сборки:**
```bash
npm run build
npm run preview
```
