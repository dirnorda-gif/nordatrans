# Структура проекта NORDA TRANS

## Обзор

Проект был реструктурирован для упрощения создания новых страниц и переиспользования компонентов.

## Основные компоненты

### 1. Глобальные компоненты (используются на всех страницах)

#### Header (`src/components/Header.tsx`)
- Навигационное меню с логотипом
- Контактная информация (телефон, WhatsApp)
- Светлый фон с адаптивным дизайном
- Используется на всех страницах

#### Footer (`src/components/Footer.tsx`)
- Информация о компании
- Быстрые ссылки
- Контактные данные
- Используется на всех страницах

### 2. Переиспользуемые секции

#### WorkProcess (`src/components/WorkProcess.tsx`)
Секция "Работаем быстро!" с 4 этапами работы:
- Отправляете запрос
- Уточняем детали
- Заключаем договор
- Доставляем груз

**Использование:**
```tsx
import WorkProcess from "@/components/WorkProcess";

<WorkProcess />
```

#### Reviews (`src/components/Reviews.tsx`)
Карусель отзывов с Яндекс.Карт:
- Автопрокрутка каждые 5 секунд
- Ручное управление стрелками
- 8 реальных отзывов
- Интеграция с Яндекс.Картами

**Использование:**
```tsx
import Reviews from "@/components/Reviews";

<Reviews />
```

#### RoutesAccordion (`src/components/RoutesAccordion.tsx`)
Аккордеон с популярными маршрутами и ценами:
- Список маршрутов с ценами по весу
- Время доставки
- Кнопка заказа

**Использование:**
```tsx
import RoutesAccordion from "@/components/RoutesAccordion";
import routeCacheData from "@/data/routeCache.json";

const routes = routeCacheData.routes.toMoscow; // или fromMoscow

<RoutesAccordion 
  routes={routes}
  onOrderClick={(route) => {
    // Обработка клика на "Заказать перевозку"
    console.log("Заказ маршрута:", route);
  }}
/>
```

### 3. UI компоненты (Shadcn)

Находятся в `src/components/ui/`:
- `button.tsx` - Кнопки
- `input.tsx` - Поля ввода
- `card.tsx` - Карточки
- `accordion.tsx` - Аккордеоны
- `slider.tsx` - Слайдеры
- и другие...

## Структура страниц

### Главная страница (`src/pages/Index.tsx`)

Содержит:
- Hero секция с фоновым изображением
- Калькулятор доставки (сложный компонент с множеством состояний)

- Секция "Работаем быстро" (можно заменить на `WorkProcess`)

```tsx

```

## Рекомендации по дальнейшей работе

### 1. Калькулятор
Калькулятор на главной странице (`Index.tsx`) **НЕ был вынесен** в отдельный компонент из-за:
- Множества состояний (более 30 переменных состояния)
- Сложной логики расчета
- Интеграции с Яндекс.Картами
- Взаимосвязи с другими секциями страницы

**Если нужно переиспользовать калькулятор на других страницах:**
1. Создайте компонент `Calculator.tsx`
2. Перенесите всю логику состояний
3. Создайте пропсы для колбэков (onSubmit, onCalculate и т.д.)

### 2. Обновление главной страницы
Вы можете обновить `Index.tsx`, чтобы использовать новые компоненты:

**Было:**
```tsx
{/* Work Process Section - Работаем быстро! */}
<section className="w-full py-16">
  {/* ... 200+ строк кода ... */}
</section>
```

**Стало:**
```tsx
<WorkProcess />
```

### 3. Добавление новых секций
Для создания новой переиспользуемой секции:
1. Создайте файл в `src/components/` (например, `FAQ.tsx`)
2. Реализуйте компонент
3. Экспортируйте его
4. Импортируйте на нужных страницах
