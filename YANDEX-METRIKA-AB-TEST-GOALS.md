# 🎯 Настройка целей Яндекс.Метрики для A/B теста

## Цели для создания

### 1. Цель: Начало заполнения формы
- **Название**: `Начало заполнения формы`
- **Идентификатор**: `form_start_filling`
- **Тип**: JavaScript-событие
- **Условие**: `reachGoal('form_start_filling')`

### 2. Цель: Отправка формы - Вариант A
- **Название**: `Форма отправлена (Вариант A)`
- **Идентификатор**: `form_submit_variant_a`
- **Тип**: JavaScript-событие
- **Условие**: `reachGoal('form_submit_variant_a')`

### 3. Цель: Отправка формы - Вариант B
- **Название**: `Форма отправлена (Вариант B)`
- **Идентификатор**: `form_submit_variant_b`
- **Тип**: JavaScript-событие
- **Условие**: `reachGoal('form_submit_variant_b')`

## Создание сегментов

### Сегмент 1: Пользователи варианта A
1. Перейдите в **Отчёты** → **Стандартные отчёты** → **Посетители**
2. Нажмите **Добавить сегмент**
3. Название: `A/B Тест - Вариант A`
4. Условие: **Параметры визита** → `ab_test_variant` = `A`

### Сегмент 2: Пользователи варианта B
1. Перейдите в **Отчёты** → **Стандартные отчёты** → **Посетители**
2. Нажмите **Добавить сегмент**
3. Название: `A/B Тест - Вариант B`
4. Условие: **Параметры визита** → `ab_test_variant` = `B`

## Отчёты для анализа

### 1. Конверсия по вариантам
**Отчёт**: Конверсии → Цели
- Применить сегмент "Вариант A"
- Посмотреть конверсию целей `form_start_filling` и `form_submit_variant_a`
- Применить сегмент "Вариант B"
- Посмотреть конверсию целей `form_start_filling` и `form_submit_variant_b`

### 2. Воронка для варианта A (3 этапа)
1. **Шаг 1**: Просмотр страницы (параметр `ab_test_variant = A`)
2. **Шаг 2**: Начало заполнения (цель `form_start_filling`)
3. **Шаг 3**: Отправка формы (цель `form_submit_variant_a`)

### 3. Воронка для варианта B (3 этапа)
1. **Шаг 1**: Просмотр страницы (параметр `ab_test_variant = B`)
2. **Шаг 2**: Начало заполнения (цель `form_start_filling`)
3. **Шаг 3**: Отправка формы (цель `form_submit_variant_b`)

### 4. Анализ потерь
**Где теряются пользователи:**
- **Между просмотром и началом заполнения**: пользователь не заинтересовался
- **Между началом и отправкой**: проблемы с формой или недоверие

## Дополнительные параметры для анализа

### Параметр: Способ связи (только для варианта A)
В событии `form_submit_variant_a` передаётся параметр `contact_method`:
- `phone` - выбрано СМС
- `whatsapp` - выбран WhatsApp

Это позволит анализировать предпочтения пользователей по способу связи.

## Формулы для расчёта

### Конверсия варианта A:
```
Конверсия A = (Цель form_submit_variant_a) / (Визиты с параметром ab_test_variant=A) × 100%
```

### Конверсия варианта B:
```
Конверсия B = (Цель form_submit_variant_b) / (Визиты с параметром ab_test_variant=B) × 100%
```

### Статистическая значимость:
Используйте онлайн-калькулятор A/B тестов:
- https://www.optimizely.com/sample-size-calculator/
- https://abtestguide.com/calc/

Минимальная выборка: **100 конверсий** на каждый вариант

## Пример анализа

### Если через 2 недели:
- **Вариант A**: 150 показов, 45 конверсий = **30% конверсия**
- **Вариант B**: 150 показов, 30 конверсий = **20% конверсия**

**Вывод**: Вариант A показывает на 50% лучшую конверсию (30% vs 20%)

### Дополнительный анализ:
- Качество лидов (сколько дозвонились)
- Средний чек по каждому варианту
- Время заполнения формы
- Процент отказов на каждом шаге
