## 🐛 Исправленные проблемы

### 1. Отсутствие важного предупреждения на мобильных

**Проблема:**  
В компактной версии блока цены на мобильных устройствах пропало важное текстовое предупреждение:

> ⚠️ ВАЖНО: Это предварительный расчёт на основе указанных данных.  
> Отправьте эту форму, указав как вы хотите получить точный расчёт.

Это предупреждение критично для бизнеса, так как объясняет клиентам, что цена предварительная.

**Решение:**  
Добавлено предупреждение обратно в компактную версию блока цены для мобильных устройств:

```tsx
{/* Предупреждение для мобильных */}
<p className="text-xs text-white/80 leading-relaxed text-center mb-2">
  ⚠️ ВАЖНО: Это предварительный расчёт на основе указанных данных. 
  Отправьте эту форму, указав как вы хотите получить точный расчёт.
</p>
```

**Результат:**
- ✅ Предупреждение снова видно на мобильных
- ✅ Уменьшенный размер шрифта (text-xs) для компактности
- ✅ Центрированный текст
- ✅ Сохранена читаемость

### 2. Нежелательное автопереключение на корзину в конструкторе

**Проблема:**  
При добавлении первого предмета в конструкторе переезда происходило автоматическое переключение на вкладку "Корзина". Это мешало пользователям, которые хотели продолжить выбор предметов.

**Последовательность:**
1. Пользователь открывает конструктор
2. Добавляет первый предмет
3. ❌ Автоматически переключается на "Корзину"
4. ❌ Приходится вручную переключаться обратно на "Выбор предметов"
5. ❌ Процесс прерывается

**Было в коде:**
```tsx
const addItem = (item: MovingItem) => {
  // ... логика добавления
  
  // 📱 Автопереключение на вкладку "Корзина" при добавлении первого предмета
  if (window.innerWidth < 1024 && selectedItems.length === 0) {
    setTimeout(() => setMobileTab('cart'), 300);
  }
};
```

**Стало:**
```tsx
const addItem = (item: MovingItem) => {
  // ... логика добавления (без автопереключения)
};
```

**Результат:**
- ✅ Пользователь остается на вкладке "Выбор предметов"
- ✅ Может продолжать добавлять предметы без прерываний
- ✅ Переключение на корзину только по желанию пользователя
- ✅ Более естественный UX-флоу

## 💡 Обоснование решений

### Почему убрали автопереключение?

1. **Прерывание флоу:** Пользователь обычно хочет добавить несколько предметов подряд
2. **Дополнительные действия:** Каждый раз нужно переключаться обратно
3. **Когнитивная нагрузка:** Неожиданное переключение дезориентирует
4. **Противоречие ожиданиям:** В других интерфейсах (интернет-магазины) так не работает

### Пример из e-commerce:

- Amazon: добавляешь товар → остаешься на странице товаров
- Ozon: добавляешь товар → остаешься в каталоге
- Wildberries: добавляешь товар → остаешься в категории

**Вывод:** Пользователь сам решает, когда перейти в корзину.

### Почему вернули предупреждение?

1. **Юридическая защита:** Клиент предупрежден, что цена предварительная
2. **Снижение конфликтов:** Меньше претензий о несоответствии цены
3. **Повышение доверия:** Прозрачность в коммуникации
4. **Конверсия:** Понимание, что нужно отправить форму для точного расчёта
