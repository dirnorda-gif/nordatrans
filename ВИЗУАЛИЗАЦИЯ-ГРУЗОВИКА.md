# Визуализация загрузки грузового автомобиля

## 📦 Описание

Добавлена интерактивная визуализация грузовика в калькуляторе на втором шаге раздела "Домашний переезд". Визуализация показывает **реальное фото грузовика** слева и **вид кузова сверху** справа с анимированным заполнением, помогая пользователю наглядно понять объем груза.

## 🎨 Возможности

### 1. **Двойная визуализация**
- **Слева**: Реальная фотография грузовика из автопарка компании
- **Справа**: Вид кузова сверху с анимированным заполнением и сеткой палет
- Компактный дизайн с двумя колонками для максимальной наглядности
- Плавные переходы при изменении объема (0.7s cubic-bezier)

### 2. **Цветовая индикация загруженности**
- 🟢 **Зеленый** (0-30%) — Легкая загрузка
- 🔵 **Синий** (30-60%) — Оптимальная загрузка
- 🟠 **Оранжевый** (60-90%) — Хорошая загрузка
- 🔴 **Красный** (90-100%) — Максимальная загрузка

### 3. **Реальные фотографии из автопарка**
- Используются фактические фотографии грузовиков компании (`/1.webp`, `/2.webp`, и т.д.)
- Точные размеры кузова из данных автопарка
- Информация о грузоподъемности и количестве паллето-мест
- Описание каждого типа транспорта

### 4. **Визуализация палет**
- Динамическая сетка палет в кузове
- Количество палет меняется в зависимости от процента заполнения
- Показывает примерное количество загруженных палет

### 5. **Информационные блоки**
- Название транспорта в заголовке
- Размеры кузова (длина × ширина × высота)
- Текущий объем и максимальная вместимость
- Процент заполнения с цветовой индикацией
- Компактная статистика (объем, загрузка, статус)

### 6. **Умные подсказки**
В зависимости от уровня загрузки показываются разные подсказки:
- До 50%: "💡 Можно добавить груз"
- 50-90%: "✓ Оптимально"
- 90%+: "⚠️ Проверьте габариты"

### Расчет процента заполнения
```typescript
const fillPercentage = Math.min((currentVolume / maxVolume) * 100, 100);
```

## 🔧 Техническая реализация

### Структура компонента
1. **Маппинг изображений** - связывает типы грузовиков с фото из автопарка
2. **Данные размеров** - точные размеры кузова и количество палет для каждого типа
3. **Левая колонка** - фото грузовика с описанием
4. **Правая колонка** - SVG визуализация кузова сверху

### SVG элементы (вид сверху)
1. **Контур кузова** - прямоугольник, показывающий границы кузова
2. **Заполнение** - анимированная область, показывающая загруженную часть
3. **Сетка палет** - динамическая сетка, визуализирующая паллето-места
4. **Процент** - крупная текстовая метка в центре
5. **Цветовая индикация** - изменение цвета в зависимости от загруженности

### Оптимизация
- Использование `useMemo` для расчета процента заполнения
- Минимальное количество re-renders
- CSS transitions вместо JS анимаций

## 🚀 Использование

Компонент автоматически отображается когда:
1. Пользователь находится на странице с калькулятором
2. Выбран тип перевозки "Домашний переезд"
3. Пользователь перешел на шаг 2
4. Выбран объем груза > 0 м³

При перемещении слайдера объема визуализация обновляется в реальном времени.
