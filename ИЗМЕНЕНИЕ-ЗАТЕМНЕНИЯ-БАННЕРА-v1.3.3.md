# 🎨 Изменение затемнения баннера "Правильные переезды"

**Дата:** 5 ноября 2025  
**Компонент:** BannerUp.tsx  
**Страница:** /pereezd (Переезды)

---

## 🎯 Что было изменено

Уменьшено затемнение белого оверлея на баннере "NORDA TRANS - Правильные переезды" на странице переездов.

### До изменения:
```tsx
<div className="absolute inset-0 bg-white/40"></div>
```
- Непрозрачность: **40%**
- Результат: Сильное затемнение, фото диплома менее заметно

### После изменения:
```tsx
<div className="absolute inset-0 bg-white/25"></div>
```
- Непрозрачность: **25%**
- Результат: Легкое затемнение, фото диплома видно лучше ✨

---

## 📁 Измененный файл

**Файл:** `src/components/BannerUp.tsx`  
**Строка:** 79

### Полный контекст изменения:

```tsx
{/* White Overlay (только для white типа) */}
{overlayType === 'white' && (
  <div className="absolute inset-0 bg-white/25"></div>  // Было: bg-white/40
)}
```

## 📝 Связанные компоненты

### BannerUp.tsx
Универсальный компонент баннера с поддержкой разных типов оверлея:
- `white` - белый оверлей (используется на странице переездов)
- `dark` - темный оверлей
- `blue` - синий оверлей
- `none` - без оверлея

### BannerUpPereezd.tsx
Специализированный компонент для страницы переездов:
- Использует `overlayType="white"`
- Фоновое изображение: `/diploma.webp`
- Декоративные элементы: кружки, линии, геометрические фигуры
