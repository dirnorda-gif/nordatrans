## 📋 Реализованные функции

### 1. ✅ Цели Яндекс.Метрики (3 цели)

| Цель | Триггер | Реализация | Параметры |
|------|---------|------------|-----------|
| `new_lead` | Отправка формы на сайте | TypeScript (клиент) | `lead_id` |
| `success_deal` | Выигранная сделка в Bitrix24 | PHP вебхук (сервер) | `revenue` (сумма) |
| `lost_deal` | Проигранная сделка в Bitrix24 | PHP вебхук (сервер) | - |
| `phone_call` | Квалифицированный звонок | PHP вебхук (сервер) | `lead_id` |

### 2. ✅ Коллтрекинг звонков

**Функционал:**
- Сохранение каждого расчета с сайта (Client ID + маршрут + время)
- Сопоставление звонков с визитами по маршруту и времени
- Отправка цели `phone_call` с привязкой к источнику рекламы

**Точность:** 70-95% (зависит от времени между расчетом и звонком)

```

    ↓
success_deal        0.5-1%
```

```
Яндекс Директ:
- Потрачено: 50 000 ₽
- Лидов (new_lead): 25
- Звонков (phone_call): 15
- Сделок (success_deal): 5
- Выручка: 250 000 ₽
- ROI: 400%
```

#### Конверсия лид → клиент:
```
new_lead: 100 шт
├─ phone_call: 60 шт (60% звонят)
├─ success_deal: 15 шт (15% покупают) ✅
└─ lost_deal: 85 шт (85% отвал) ❌
```


#### Вебхук 2: Для phone_call (коллтрекинг)

**Путь:** CRM → Автоматизация → Лиды → Стадия "Квалифицирован"

- Робот: Исходящий вебхук
- URL: `https://nordatrans.ru/api/match-call-lead.php?token=cd7p8htqy86kby1wu8ajqa7bpr2kbmfl`
- Условия:
  - Источник = Звонок
  - Телефон содержит `4994440651`
  - Откуда ≠ пусто
  - Куда ≠ пусто
