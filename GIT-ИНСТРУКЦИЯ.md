## 🎯 WORKFLOW (порядок работы)

### 1. Проверяем что мы на правильной ветке
```bash
git branch --show-current
# Должно быть: feature/new-commercial-logic
```

### 2. Работаем над кодом
- Редактируем файлы
- Тестируем изменения
- Проверяем что всё работает

### 3. Сохраняем изменения
```bash
git add .
git commit -m "Описание изменений"
```

### 4. Если всё хорошо - объединяем с main
```bash
git checkout main
git merge feature/new-commercial-logic
```

### 5. Создаем новый тег для новой версии
```bash
git tag -a v2.0-new-logic -m "Версия с НОВОЙ логикой калькулятора"
```

## ⚠️ ЧТО ДЕЛАТЬ ЕСЛИ...

### ...я случайно удалил файл?
```bash
git checkout HEAD -- путь/к/файлу
```

### ...я хочу отменить последний коммит (но сохранить изменения)?
```bash
git reset --soft HEAD~1
```

### ...я хочу отменить последний коммит (и удалить изменения)?
```bash
git reset --hard HEAD~1
```

### ...я хочу посмотреть старую версию файла?
```bash
git show v1.0-old-logic:src/utils/shippingCalculator.ts
```

### ...я хочу восстановить файл из старой версии?
```bash
git checkout v1.0-old-logic -- src/utils/shippingCalculator.ts
```
