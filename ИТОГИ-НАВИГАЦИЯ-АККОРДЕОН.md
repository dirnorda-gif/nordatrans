# Итоги: Навигация при переключении направлений в аккордеоне

## Дата выполнения
28 октября 2025

## Задача
Реализовать навигацию по URL при переключении кнопок "В Москву" и "Из Москвы" в аккордеоне маршрутов с сохранением позиции скролла.

## Реализованная функциональность

### 1. Навигация при переключении направлений

Кнопки "В Москву" и "Из Москвы" теперь работают как полноценная навигация:

| Текущая страница | Кнопка "Из Москвы" → | Кнопка "В Москву" → |
|------------------|----------------------|---------------------|
| `/tarify` | `/tarify-iz-moskvy` | `/tarify` |
| `/tarify-iz-moskvy` | `/tarify-iz-moskvy` | `/tarify` |
| `/pereezd` | `/pereezd-iz` | `/pereezd` |
| `/pereezd-iz` | `/pereezd-iz` | `/pereezd` |
| `/` (главная) | Без навигации | Без навигации |

### 2. Сохранение позиции скролла

При переключении направлений аккордеон остается на месте - позиция скролла сохраняется.

## Технические изменения

### Измененные файлы

#### 1. `src/components/RoutesAccordion.tsx`

**Добавлено:**
- Импорт `useNavigate` и `useLocation` из `react-router-dom`
- Функция `handleDirectionChange()` - обрабатывает переключение направлений с навигацией
- useEffect для восстановления позиции скролла
- useEffect для синхронизации направления с URL

**Ключевые изменения:**

```typescript
// 1. Хуки навигации
const navigate = useNavigate();
const location = useLocation();

// 2. Функция переключения с навигацией и сохранением позиции
const handleDirectionChange = (newDirection: "to-moscow" | "from-moscow") => {
  const scrollPosition = window.scrollY;
  
  navigate(targetUrl, { 
    state: { 
      preserveScroll: true,
      scrollPosition: scrollPosition
    }
  });
};

// 3. Восстановление позиции скролла
useEffect(() => {
  const state = location.state as { preserveScroll?: boolean; scrollPosition?: number } | null;
  
  if (state?.preserveScroll && typeof state.scrollPosition === 'number') {
    requestAnimationFrame(() => {
      window.scrollTo({
        top: state.scrollPosition,
        behavior: 'instant'
      });
    });
  }
}, [location.state]);

// 4. Синхронизация направления с URL
useEffect(() => {
  if (location.pathname === '/tarify-iz-moskvy' || location.pathname === '/pereezd-iz') {
    setRouteDirection('from-moscow');
  } else if (location.pathname === '/tarify' || location.pathname === '/pereezd') {
    setRouteDirection('to-moscow');
  }
}, [location.pathname]);
```

#### 2. `src/components/ScrollToTop.tsx`

**Изменено:**
- Добавлена проверка флага `preserveScroll` в `location.state`
- Если флаг установлен - стандартный скролл вверх пропускается

```typescript
useEffect(() => {
  const state = location.state as { preserveScroll?: boolean } | null;
  
  // Если флаг preserveScroll не установлен - скроллим вверх
  if (!state?.preserveScroll) {
    window.scrollTo(0, 0);
  }
}, [location.pathname, location.state]);
```
