# Настройка аккордеона маршрутов

## Описание

Компонент `RoutesAccordion` позволяет отображать список популярных маршрутов с возможностью ограничения количества видимых элементов и кнопкой "Еще маршруты" для раскрытия полного списка.

## Параметры компонента

### `initialVisibleCount` (необязательный)
- **Тип:** `number`
- **По умолчанию:** `6`
- **Описание:** Количество маршрутов, которые будут видны изначально. Остальные маршруты скрываются до нажатия кнопки "Еще маршруты".

### `showMoreButton` (необязательный)
- **Тип:** `boolean`
- **По умолчанию:** `true`
- **Описание:** Показывать ли кнопку "Еще маршруты". Если `false`, то все маршруты отображаются сразу.

### `initialDirection` (необязательный)
- **Тип:** `"to-moscow" | "from-moscow"`
- **По умолчанию:** `"to-moscow"`
- **Описание:** Начальное направление маршрутов. `"to-moscow"` - активна кнопка "В Москву", `"from-moscow"` - активна кнопка "Из Москвы".

## Примеры использования

### 1. Базовое использование (по умолчанию)
Показывает 6 маршрутов с кнопкой "Еще маршруты":
```tsx
<RoutesAccordion />
```

### 2. Ограничение до 3 маршрутов
```tsx
<RoutesAccordion initialVisibleCount={3} />
```

### 3. Показать 10 маршрутов
```tsx
<RoutesAccordion initialVisibleCount={10} />
```

### 4. Показать все маршруты без кнопки
```tsx
<RoutesAccordion showMoreButton={false} />
```

### 5. Начальное направление "Из Москвы"
```tsx
<RoutesAccordion initialDirection="from-moscow" />
```

### 6. Начальное направление "В Москву" (по умолчанию)
```tsx
<RoutesAccordion initialDirection="to-moscow" />
```

### 7. Кастомная настройка
Показать 8 маршрутов с кнопкой из Москвы:
```tsx
<RoutesAccordion initialVisibleCount={8} showMoreButton={true} initialDirection="from-moscow" />
```

## Где используется

Компонент используется на следующих страницах:

1. **`src/pages/Moving.tsx`** - страница переезда (по умолчанию "В Москву")
2. **`src/pages/PereezdIz.tsx`** - страница переезда из Москвы (по умолчанию "Из Москвы")
3. **`src/pages/Tariffs.tsx`** - страница тарифов (по умолчанию "В Москву")
4. **`src/pages/TariffyIzMoskvy.tsx`** - страница тарифов из Москвы (по умолчанию "Из Москвы")

## Как настроить для конкретной страницы

### Пример: Изменить количество видимых маршрутов на странице Moving

**До:**
```tsx
<RoutesAccordion />
```

**После (показать 4 маршрута):**
```tsx
<RoutesAccordion initialVisibleCount={4} />
```

### Пример: Показать все маршруты на странице Tariffs

**До:**
```tsx
<RoutesAccordion />
```

**После:**
```tsx
<RoutesAccordion showMoreButton={false} />
```

## Логика работы

1. При загрузке компонента отображается только `initialVisibleCount` маршрутов
2. Если общее количество маршрутов больше `initialVisibleCount`, появляется кнопка "Еще маршруты (N)", где N - количество скрытых маршрутов
3. При клике на кнопку раскрываются все оставшиеся маршруты
4. Кнопка исчезает после раскрытия всех маршрутов

## Рекомендации

- **Для главной страницы:** используйте `initialVisibleCount={6}` (по умолчанию) - оптимальный баланс между информативностью и компактностью
- **Для страницы тарифов:** можно использовать `initialVisibleCount={10}` или `showMoreButton={false}` для показа максимального количества информации
- **Для мобильных устройств:** рекомендуется ограничение в 3-4 маршрута для лучшего UX

## Техническая информация

- **Файл компонента:** `src/components/RoutesAccordion.tsx`
- **Состояние раскрытия:** управляется внутренним state компонента (`useState`)
- **Данные маршрутов:** загружаются из `src/data/routeCache.json` с задержкой 1 секунда после монтирования компонента
- **Переключение направлений:** В Москву / Из Москвы работает независимо от количества видимых маршрутов
