# Сохранение позиции скролла при переключении направлений в аккордеоне

## Обзор

Реализована функциональность сохранения позиции скролла при переключении кнопок "В Москву" и "Из Москвы" в аккордеоне маршрутов. Теперь при переключении направления аккордеон остается на месте, улучшая пользовательский опыт.

### Архитектурное решение

- **Компонент `RoutesAccordion`** - содержит всю логику сохранения и восстановления позиции скролла
- **Компонент `ScrollToTop`** - проверяет флаг `preserveScroll` и пропускает стандартный скролл вверх при его наличии
- **Связь через `location.state`** - позиция скролла передается между страницами через React Router state

## Технические детали

### 1. Компонент `RoutesAccordion.tsx`

Вся логика сохранения и восстановления позиции скролла находится внутри этого компонента.

**Добавлены импорты:**
```typescript
import { useNavigate, useLocation } from "react-router-dom";
```

**Механизм сохранения позиции скролла:**

```typescript
const handleDirectionChange = (newDirection: "to-moscow" | "from-moscow") => {
  // ... код определения маршрута ...
  
  // Сохраняем текущую позицию скролла перед навигацией
  const scrollPosition = window.scrollY;
  
  // Передаем информацию о позиции через state
  navigate(targetUrl, { 
    state: { 
      preserveScroll: true,
      scrollPosition: scrollPosition
    }
  });
}
```

**Механизм восстановления позиции скролла:**

```typescript
// Восстановление позиции скролла после навигации
useEffect(() => {
  const state = location.state as { preserveScroll?: boolean; scrollPosition?: number } | null;
  
  if (state?.preserveScroll && typeof state.scrollPosition === 'number') {
    // Восстанавливаем сохраненную позицию скролла
    requestAnimationFrame(() => {
      window.scrollTo({
        top: state.scrollPosition,
        behavior: 'instant'
      });
    });
  }
}, [location.state]);
```

### 2. Компонент `ScrollToTop.tsx`

Минимальная модификация для поддержки флага `preserveScroll`:

```typescript
useEffect(() => {
  const state = location.state as { preserveScroll?: boolean } | null;
  
  // Если флаг preserveScroll не установлен - скроллим вверх
  if (!state?.preserveScroll) {
    window.scrollTo(0, 0);
  }
}, [location.pathname, location.state]);
```

## Как это работает

1. **Пользователь кликает на кнопку переключения направления** (например, с "В Москву" на "Из Москвы")

2. **RoutesAccordion сохраняет текущую позицию скролла:**
   - Считывает `window.scrollY`
   - Передает значение через `state` в `navigate()`

3. **React Router выполняет навигацию:**
   - URL изменяется (например, `/tarify` → `/tarify-iz-moskvy`)
   - `state` с позицией скролла передается на новую страницу

4. **ScrollToTop проверяет флаг `preserveScroll`:**
   - Если флаг установлен - пропускает скролл вверх
   - Если флага нет - скроллит вверх (стандартное поведение для других страниц)

5. **RoutesAccordion восстанавливает позицию:**
   - Считывает сохраненную позицию из `location.state`
   - Использует `requestAnimationFrame` для синхронизации с отрисовкой
   - Применяет `behavior: 'instant'` для мгновенного скролла

## Поддерживаемые страницы

Сохранение позиции скролла работает на следующих страницах:

| Страница "В Москву" | Страница "Из Москвы" |
|---------------------|----------------------|
| `/tarify` | `/tarify-iz-moskvy` |
| `/pereezd` | `/pereezd-iz` |

На главной странице `/` переключение происходит без навигации (только изменение состояния).
