# 🔄 Версионирование тарифов и автоматическая проверка кэша

## 📋 Обзор системы

Система автоматически проверяет соответствие версий тарифов между `tariffConfig` (в коде) и `routeCache.json` (кэш для аккордеона).

## 🎯 Как это работает

1. **Версия тарифов хранится в коде** (`src/utils/shippingCalculator.ts`):
   ```typescript
   export const TARIFF_VERSION = "1.0.0";
   ```

2. **Версия тарифов хранится в кэше** (`src/data/routeCache.json`):
   ```json
   {
     "tariffVersion": "1.0.0"
   }
   ```

3. **Автоматическая проверка** при загрузке кэша:
   - Если версии совпадают → всё ОК ✅
   - Если версии не совпадают → КРИТИЧЕСКОЕ предупреждение в консоли 🚨

## 🔧 Изменение тарифов: пошаговая инструкция

### Шаг 1: Измените тарифы в коде

Откройте `src/utils/shippingCalculator.ts` и измените тарифы в `tariffConfig`:

```typescript
const tariffConfig: TariffConfig = {
  fromMoscow: {
    "Новосибирск": "73.8/65.1/0/0/0/0",  // ← изменили тариф
    // ...
  }
};
```

### Шаг 2: Увеличьте версию тарифов

В том же файле найдите:

```typescript
export const TARIFF_VERSION = "1.0.0";  // ← УВЕЛИЧЬТЕ версию!
export const TARIFF_UPDATED_AT = "2025-01-28";  // ← Обновите дату
```

Измените на:

```typescript
export const TARIFF_VERSION = "1.0.1";  // Мажорная версия.Минорная версия
export const TARIFF_UPDATED_AT = "2025-01-29";
```

### Шаг 3: Сохраните и запустите приложение

При загрузке приложения в консоли браузера появится:

```
🚨 КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ: Версии тарифов не совпадают!
   Версия тарифов в routeCache.json: 1.0.0
   Текущая версия тарифов в коде: 1.0.1
   
   ❌ Аккордеон показывает УСТАРЕВШИЕ цены!
   ✅ Калькулятор использует АКТУАЛЬНЫЕ тарифы.
```

### Шаг 4: Обновите routeCache.json

1. Пересчитайте цены для всех маршрутов (используйте скрипты расчета)
2. Обновите `src/data/routeCache.json`:
   ```json
   {
     "version": "1.0.1",
     "tariffVersion": "1.0.1",  // ← Должно совпадать с TARIFF_VERSION
     "generatedAt": "2025-01-29T12:00:00.000Z",
     // ... обновленные цены
   }
   ```

3. После обновления предупреждение исчезнет:
   ```
   ✅ Версия тарифов совпадает (1.0.1) - кэш актуален
   ```

## 📊 Пример сценария

### Сценарий: Изменение тарифа Москва → Новосибирск

**Было:**
```typescript
"Новосибирск": "73.8/65.1/0/0/0/0"
TARIFF_VERSION = "1.0.0"
```

**Стало:**
```typescript
"Новосибирск": "80.0/65.1/0/0/0/0"  // Изменили тариф 20т с 73.8 на 80.0
TARIFF_VERSION = "1.0.1"  // Увеличили версию
```

**Результат:**
- ✅ Калькулятор сразу использует новые тарифы (80.0)
- ❌ Аккордеон показывает старые цены (до обновления routeCache.json)
- 🚨 В консоли появится предупреждение о несоответствии

## 🔍 Проверка версий

### В коде (TypeScript):
```typescript
import { TARIFF_VERSION } from "@/utils/shippingCalculator";
console.log("Версия тарифов:", TARIFF_VERSION);
```

### В консоли браузера:
```javascript
// После загрузки страницы проверьте сообщения в консоли
// Ищите: "✅ Версия тарифов совпадает" или "🚨 КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ"
```

## ⚠️ Важные моменты

1. **Версионирование:**
   - Используйте формат `MAJOR.MINOR` (например: `1.0.0`, `1.0.1`, `1.1.0`)
   - Минорная версия (`.1`, `.2`) — для изменений тарифов
   - Мажорная версия (`2.0`) — для кардинальных изменений логики

2. **Всегда увеличивайте версию:**
   - При изменении ЛЮБОГО тарифа в `tariffConfig`
   - При изменении коэффициентов
   - Даже если это один маршрут

3. **Синхронизация:**
   - `TARIFF_VERSION` в коде = `tariffVersion` в routeCache.json
   - Это обеспечивает автоматическое обнаружение несоответствий

4. **Предупреждения в консоли:**
   - Красное предупреждение = КРИТИЧНО, нужно обновить кэш
   - Оранжевое предупреждение = нет версии в кэше (старый формат)
   - Зеленое сообщение = всё ОК
