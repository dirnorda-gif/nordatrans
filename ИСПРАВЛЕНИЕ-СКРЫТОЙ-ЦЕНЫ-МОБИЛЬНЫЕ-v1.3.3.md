# Исправление скрытой цены на мобильных устройствах

**Версия:** v1.3.3  
**Дата:** 4 ноября 2025  
**Компонент:** `src/components/ShippingCalculatorForm.tsx`

---

## 🐛 Проблема

На финальном шаге калькулятора (шаг 2) при открытии формы контактов блок с **предварительной ценой полностью скрывался на мобильных устройствах**.

### Причина

В коде была следующая логика (строка 1081):

```tsx
<div className={`${showContactForm ? 'hidden md:block' : 'block'}`}>
```

Когда форма контактов открывалась (`showContactForm === true`), блок с ценой получал классы:
- `hidden` - скрыт на всех размерах
- `md:block` - виден только на ≥768px

**Результат:** На мобильных (< 768px) цена полностью исчезала! ❌

---

## ✅ Решение

Создана **двойная система отображения цены**:

### 1. 📱 Компактная версия для мобильных

Показывается **только на мобильных** (`md:hidden`) **когда форма контактов открыта**:

```tsx
<div className={`md:hidden ${showContactForm ? 'block' : 'hidden'}`}>
  <div className="flex items-center justify-center gap-4 mb-3 pb-3 border-b border-white/20">
    {/* Цена */}
    <div className="text-center">
      <p className="text-xs text-white/70 mb-0.5">Примерная стоимость</p>
      <p className="text-xl font-bold text-white">{estimatedCost.toLocaleString()} ₽</p>
    </div>
    
    {/* Расстояние */}
    <div className="text-center border-l border-white/20 pl-4">
      <p className="text-xs text-white/70 mb-0.5">Расстояние</p>
      <p className="text-sm font-semibold text-white">{routeDistance.toLocaleString()} км</p>
    </div>
    
    {/* Срок доставки */}
    <div className="text-center border-l border-white/20 pl-4">
      <p className="text-xs text-white/70 mb-0.5">Доставка</p>
      <p className="text-sm font-semibold text-white">
        {routeDuration} {routeDuration === 1 ? 'день' : routeDuration < 5 ? 'дня' : 'дней'}
      </p>
    </div>
  </div>
</div>
```

**Особенности компактной версии:**
- ✅ Горизонтальное расположение всех элементов
- ✅ Уменьшенные размеры шрифтов (text-xl вместо text-2xl для цены)
- ✅ Разделители между элементами (border-l)
- ✅ Компактный padding (mb-3 pb-3)
- ✅ Убраны длинные текстовые предупреждения
- ✅ Только ключевая информация

### 2. 💻 Полная версия для десктопов

Сохранена прежняя логика - показывается:
- На десктопах всегда
- На мобильных только когда форма закрыта

```tsx
<div className={`${showContactForm ? 'hidden md:block' : 'block'}`}>
  {/* Прежний код с полной версией */}
</div>
```
