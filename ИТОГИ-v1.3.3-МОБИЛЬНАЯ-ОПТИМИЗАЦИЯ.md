### 2. Автоскролл к ошибкам (ShippingCalculatorForm.tsx)

#### 2.1 Проблема, которую решили

На мобильных устройствах при ошибке валидации:
- Пользователь не видит, какое поле заполнено неправильно
- Поле "Откуда" уходит за пределы экрана когда открыта клавиатура
- Приходится вручную скроллить вверх чтобы найти ошибку

#### 2.2 Решение

Добавлен новый `useEffect` который автоматически скроллит к полю с ошибкой:

```typescript
// 📱 Автоматический скролл к полю с ошибкой на мобильных устройствах
useEffect(() => {
  if (!isMobileDevice()) return; // Только для мобильных устройств
  
  // Скроллим к полю "Откуда" если есть ошибка
  if (fromFieldError && fromInputRef.current) {
    setTimeout(() => {
      scrollToElementWithOffset(fromInputRef.current, 10);
    }, 300); // Небольшая задержка чтобы пользователь увидел сообщение об ошибке
  }
  
  // Скроллим к полю "Куда" если есть ошибка (только если нет ошибки в поле "Откуда")
  if (toFieldError && !fromFieldError && toInputRef.current) {
    setTimeout(() => {
      scrollToElementWithOffset(toInputRef.current, 10);
    }, 300);
  }
}, [fromFieldError, toFieldError]);
```

#### 2.3 Логика работы

**Приоритет ошибок:**
1. Если ошибка в поле "Откуда" → скроллим к нему
2. Если ошибка только в поле "Куда" → скроллим к нему
3. Если ошибки в обоих → скроллим только к "Откуда"

**Параметры:**
- Отступ: **10 пикселей** (по требованию)
- Задержка: **300ms** (чтобы пользователь увидел toast)
- Анимация: **smooth** (плавный скролл)
- Платформа: **только мобильные** (проверка через `isMobileDevice()`)

## 🔧 Технические детали

### Использованные функции

#### isMobileDevice()
Определяет мобильное устройство по User-Agent или ширине экрана:
```typescript
const isMobileDevice = (): boolean => {
  return /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(navigator.userAgent) 
    || window.innerWidth < 768;
};
```

#### scrollToElementWithOffset()
Плавно скроллит к элементу с заданным отступом:
```typescript
const scrollToElementWithOffset = (element: HTMLElement | null, offset: number = 15) => {
  if (!element || !isMobileDevice()) return;
  
  const elementPosition = element.getBoundingClientRect().top + window.pageYOffset;
  const targetPosition = elementPosition - offset;
  
  setTimeout(() => {
    window.scrollTo({
      top: targetPosition,
      behavior: 'smooth'
    });
  }, 100);
};
```
