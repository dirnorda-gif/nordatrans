## 📋 Где находятся настройки

Файл: `/src/pages/Index.tsx`

Строки: **53-54**

## 🔧 Как изменить данные менеджера

### Текущие значения по умолчанию:

```typescript
const [managerName, setManagerName] = useState("Дарья");
const [managerPhone, setManagerPhone] = useState("+7 (499) 444 06 51");
```

### Для изменения:

1. Откройте файл `/src/pages/Index.tsx`
2. Найдите строки 53-54
3. Измените значения в кавычках:

```typescript
// Пример изменения имени менеджера
const [managerName, setManagerName] = useState("Александра");

// Пример изменения телефона менеджера
const [managerPhone, setManagerPhone] = useState("+7 (495) 123-45-67");
```

4. Сохраните файл
5. Изменения вступят в силу автоматически
