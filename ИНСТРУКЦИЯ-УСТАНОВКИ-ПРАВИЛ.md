# 🤖 Инструкция по установке правил для AI

## Что это дает?

После установки этих правил, AI будет:
- ✅ Бережно относиться к вашему коду
- ✅ Комментировать код вместо удаления
- ✅ Тестировать изменения перед завершением
- ✅ **В конце каждого ответа показывать список измененных файлов**

---

## 🚀 Быстрая установка (для всех проектов)

### Вариант 1: Через настройки Cursor

1. Откройте Cursor
2. Нажмите `Cmd + ,` (настройки)
3. В поиске введите: `rules for ai`
4. Найдите: **Cursor: Rules for AI**
5. Нажмите **"Edit in settings.json"**
6. Скопируйте содержимое файла `AI-CODING-RULES.md`
7. Вставьте в поле `cursor.general.rulesForAI` (в виде одной строки с `\n` для переносов)

### Вариант 2: Открыть файл настроек вручную

**Mac:**
```bash
open ~/Library/Application\ Support/Cursor/User/settings.json
```

**Windows:**
- Нажмите `Win + R`
- Введите: `%APPDATA%\Cursor\User\settings.json`

**Linux:**
```bash
nano ~/.config/Cursor/User/settings.json
```

Затем добавьте правила в JSON формате.

---

## 📁 Для одного проекта

Если хотите правила только для текущего проекта:

1. Создайте файл `.cursorrules` в корне проекта
2. Скопируйте содержимое `AI-CODING-RULES.md` в этот файл
3. Перезапустите Cursor

## ✅ Проверка

После установки попросите AI сделать любое изменение в коде.  
В конце ответа должен появиться раздел **"📝 Modified Files"** со списком измененных файлов.

---

## 📋 Что включают правила?

1. **Сохранение структуры кода** - не удалять без разрешения
2. **Целевые изменения** - менять только то, что нужно
3. **Тестирование** - проверять сборку после изменений
4. **Качество кода** - следовать существующим паттернам
5. **Аккуратность с зависимостями** - не менять без одобрения
6. **Уважение к конфигурации** - не трогать настройки без запроса
7. **Отслеживание изменений** - использовать TODO списки
8. **Документация** - документировать важные изменения
9. **📋 ОБЯЗАТЕЛЬНО: Список измененных файлов** - в конце каждого ответа
