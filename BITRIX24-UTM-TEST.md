## 🔍 Исправление комментария

**Проблема:** Bitrix24 API не обрабатывает Unicode символы (━, 🚚, 📍 и т.д.)

**Решение:** Заменили на простые символы ASCII:
- `━━━` → `===`
- `🚚` → убрали
- `📍` → убрали
- `₽` → `руб.`

## ⚠️ Почему UTM метки не передаются на локальном сайте?

### Причина №1: Нет UTM меток в URL

Если вы открываете сайт просто как `http://localhost:5173/`, то UTM меток нет, и в консоли будет:

```
🔗 UTM метки в URL отсутствуют
⚠️ UTM метки не найдены ни в URL, ни в localStorage
```

**Решение:** Добавьте UTM метки в URL (см. примеры выше)

### Причина №2: UTM метки не сохранились

UTM метки сохраняются в localStorage при первом посещении с UTM параметрами.

**Проверка в консоли:**
```javascript
localStorage.getItem('utm_params')
// Должно вернуть: {"utm_source":"yandex","utm_medium":"cpc",...}
```

**Очистка кэша:**
```javascript
localStorage.clear()
// Затем откройте сайт с UTM метками заново
```

### Причина №3: Bitrix24 API не принимает UTM метки

Проверьте в Bitrix24, есть ли стандартные поля UTM:
- `UTM_SOURCE`
- `UTM_MEDIUM`
- `UTM_CAMPAIGN`
- `UTM_CONTENT`
- `UTM_TERM`

Эти поля должны быть доступны по умолчанию в Bitrix24 для лидов.

### 1. Проверка UTM меток в консоли


### 2. Проверка localStorage

```javascript

console.log('UTM timestamp:', localStorage.getItem('utm_params_timestamp'));
console.log('YM Client ID:', localStorage.getItem('ym_client_id'));
```

### 3. Ручная установка UTM меток (для теста)

```javascript
// Установите вручную в консоли
localStorage.setItem('utm_params', JSON.stringify({
  utm_source: 'test_source',
  utm_medium: 'test_medium',
  utm_campaign: 'test_campaign',
  utm_content: 'test_content',
  utm_term: 'test_term'
}));
localStorage.setItem('utm_params_timestamp', Date.now().toString());

// Перезагрузите страницу
location.reload();
```

## 📊 Проверка в Bitrix24

После отправки заявки:

1. Зайдите в **CRM** → **Лиды**
2. Найдите последний созданный лид
3. Проверьте поля:
   - **Откуда** (UF_CRM_1605030443) - должен быть город
   - **Куда** (UF_CRM_1605030456) - должен быть город
   - **Комментарий** - должен быть полный расчёт (без линий ━━━)
   - **Yandex Client ID** (UF_CRM_1759567366) - числовое значение
   - **UTM Source** - если была в URL
   - **UTM Medium** - если была в URL
   - **UTM Campaign** - если была в URL
   - **UTM Content** - если была в URL
   - **UTM Term** - если была в URL
