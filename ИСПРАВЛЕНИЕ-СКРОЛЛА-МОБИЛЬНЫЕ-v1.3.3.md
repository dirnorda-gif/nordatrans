## 🎯 Решенные проблемы

### 1. Автоматический скролл при переходе на шаг 2

**Проблема:**  
На мобильных устройствах при нажатии на кнопку "Продолжить расчёт" (переход с шага 1 на шаг 2) происходил нежелательный автоматический скролл, который работал некорректно. На десктопах проблема была решена ранее, но мобильная версия требовала отдельного подхода.

**Решение:**  
Реализован адаптивный механизм скролла с разным поведением для десктопов и мобильных устройств:
- **На мобильных:** форма прижимается к верхнему краю экрана с отступом 15px
- **На десктопах:** используется более мягкий стандартный `scrollIntoView`

### 2. Проблема с видимостью подсказок при вводе адреса

**Проблема:**  
При заполнении полей "Откуда" и "Куда" на мобильных устройствах открывается клавиатура, которая закрывает половину экрана. Пользователь плохо видит выпадающие подсказки адресов и вынужден:
1. Закрывать клавиатуру
2. Вручную скроллить форму вверх
3. Снова открывать клавиатуру
4. Продолжать ввод

**Решение:**  
При фокусе на поля "Откуда" и "Куда" на мобильных устройствах автоматически выполняется скролл, поднимающий активное поле к верхнему краю экрана с отступом 15px. Это обеспечивает видимость подсказок даже при открытой клавиатуре.

## 🔧 Технические изменения

### Добавлены новые функции

#### 1. Функция определения мобильного устройства

```typescript
// 📱 Функция для определения мобильного устройства
const isMobileDevice = (): boolean => {
  return /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(navigator.userAgent) 
    || window.innerWidth < 768;
};
```

Определяет, работает ли пользователь с мобильного устройства по:
- User-Agent браузера
- Ширине окна (< 768px считается мобильным)

#### 2. Функция скролла к элементу с отступом

```typescript
// 📱 Функция для скролла к элементу с отступом (для мобильных устройств)
const scrollToElementWithOffset = (element: HTMLElement | null, offset: number = 15) => {
  if (!element || !isMobileDevice()) return;
  
  // Получаем позицию элемента относительно документа
  const elementPosition = element.getBoundingClientRect().top + window.pageYOffset;
  
  // Вычисляем целевую позицию с учетом отступа
  const targetPosition = elementPosition - offset;
  
  // Плавно скроллим к целевой позиции
  setTimeout(() => {
    window.scrollTo({
      top: targetPosition,
      behavior: 'smooth'
    });
  }, 100);
};
```

**Особенности:**
- Работает только на мобильных устройствах
- Использует плавную анимацию скролла (`behavior: 'smooth'`)
- Задержка в 100мс для корректной работы с изменением DOM
- По умолчанию отступ = 15px

### Обновлен useEffect для перехода между шагами

**Было:**
```typescript
useEffect(() => {
  scrollPositionRef.current = window.pageYOffset;
  
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      window.scrollTo({ top: scrollPositionRef.current, behavior: 'auto' });
    });
  });
}, [calculatorStep]);
```

**Стало:**
```typescript
// 📱 Скролл к началу формы при переходе на второй шаг (важно для мобильных)
useEffect(() => {
  if (calculatorStep === 2 && calculatorRef.current) {
    // Для мобильных устройств скроллим форму к верху экрана с отступом 15px
    if (isMobileDevice()) {
      scrollToElementWithOffset(calculatorRef.current, 15);
    } else {
      // Для десктопов используем более мягкий подход
      setTimeout(() => {
        calculatorRef.current?.scrollIntoView({ 
          behavior: 'smooth', 
          block: 'start' 
        });
      }, 100);
    }
  }
}, [calculatorStep]);
```

**Преимущества:**
- Разделение логики для мобильных и десктопов
- Более надежная работа на разных устройствах
- Предсказуемое поведение при переходе на шаг 2
